The independent component analysis (ICA) spatial templates used in this study were obtained from the large-scale intrinsic connectivity network (ICN) atlas developed by Ali Iraji and colleagues. In that study, canonical multi-scale ICNs were identified using group ICA on over 100,000 resting-state fMRI datasets, including the UK Biobank, and shown to be highly replicable across datasets (Iraji et al., 2023
). These templates were then used to perform dual regression for extracting subject-specific network time series and spatial maps.
